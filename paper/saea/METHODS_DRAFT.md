# AXNetCC-SAEA methods draft

## Problem formulation

The department expert set and endpoint placement are fixed. For each golden-required role (r\), the router supplies a role-local evidence bundle (E_r\). AXNetCC-SAEA selects one representation (m\) from

\[
M=\{\text{raw},\text{sanitized},\text{local-summary},\text{metadata-only}\}.
\]

Let (P(E_r,m,z)\in\{0,1\}\) denote the synthetic boundary policy for requester zone (z\), and let (C(E_r,m)\) be concept coverage after transformation. A candidate is feasible only if

\[
P(E_r,m,z)=1 \quad\land\quad C(E_r,m)\ge \tau_r,
\]

where (τ_r\) is fixed by expert role before evaluation. If no representation is feasible, the required role is retained and the request is escalated with `humanReviewRequired`; metadata is not counted as evidence.

Among feasible modes, SAEA minimizes the lexicographic objective

\[
\left(B_m w_s,\ \widehat{T}_m,\ B_m,\ L_m\right),
\]

where (B_m\) is the application payload crossing the department boundary, (w_s\) is the synthetic sensitivity weight, ŶT_m is predicted completion time under the chosen scenario, and (L_m\) is local transformation cost. Policy and coverage are hard constraints rather than objective penalties. A weighted-sum variant is evaluated only as an ablation.

## Execution path

Each of the eight department roles owns a fixed localhost Evidence Gateway. A fixed application-layer proxy injects seeded latency, jitter, bandwidth delay, synthetic loss/503, timeout, and owner-processing multipliers. Every measured result performs an actual HTTP request through the proxy. The experiment records UTF-8 request/response payload bytes and wall-clock elapsed time; it does not claim packet-level wire bytes or physical KOREN measurements.

`raw` returns the selected source bundle, `sanitized` applies deterministic identifier redaction, `local-summary` returns a deterministic extractive summary plus evidence handles, and `metadata-only` returns no content field. Source-bundle coverage and transformed-response coverage are evaluated independently.

## Experimental hierarchy

The primary acquisition study fixes the role set to `expected_agents` so that evidence selection is not confounded with routing. It uses the existing six-query golden set, seven acquisition methods, six network scenarios, three explicitly different synthetic security profiles, and 30 repetitions. Repetitions stabilize system measurements but do not increase the statistical sample size. Ablations use the same three profiles and three repetitions. The three profiles are fixed explicitly in the derived manifest; they are not generated by an execution-time parity rule.

A separate 40-query, semantic-family-grouped five-fold study evaluates routing. Its research-derived rows are AX task adapters for [MasRouter (ACL 2025)](https://aclanthology.org/2025.acl-long.757/), [RouteLLM](https://arxiv.org/abs/2406.18665), and [IRT-Router (ACL 2025)](https://aclanthology.org/2025.acl-long.761/). They are reported as adapters rather than exact upstream checkpoint reproductions. More recent state-aware or context-routing work, including [STRMAC](https://arxiv.org/abs/2511.02200) and [RCR-Router](https://arxiv.org/abs/2508.04903), is treated as related work because the available repository has no commensurate fixed-department reproduction.

The existing 40-query set additionally supports a three-repetition HTTP acquisition validation. The 240-item LLM-adjudicated set is excluded from confirmatory claims because it is explicitly marked ineligible pending blind human review.

## Statistics

The independent unit is the unique query. For each query and method, repetitions, roles, and scenarios form a cluster. The analysis reports query-weighted means and computes empirical P50/P95 latency within clusters. Paired differences use a 10,000-resample query-cluster bootstrap with seed 20260806. A two-sided paired sign-flip test is exact when the number of queries is at most 20 and Monte Carlo otherwise. P-values are Holm-adjusted across baselines separately for each metric.

With six primary queries, the smallest attainable two-sided exact sign-flip p-value is 0.03125 before multiplicity adjustment. Consequently, uncertainty intervals and effect direction are more informative than thresholded significance for the primary systems study. The 40-query validation improves effect estimation but remains author-labelled rather than independently expert-labelled.

## Recommended table separation

1. Acquisition methods under fixed golden roles.
2. Acquisition ablations.
3. Router-only 40-query cross-validation, separating generic baselines, research adapters, proposed router, and oracle.
4. Cross-layer architecture stress test, labelled as repository-inspired rather than exact literature reproduction.

This separation prevents model routing, expert-role routing, evidence representation, and system architecture from being presented as interchangeable problems.
