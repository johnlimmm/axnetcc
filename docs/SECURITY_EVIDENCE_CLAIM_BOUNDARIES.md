# Security evidence claim boundaries

Permitted claims: fixed department gateways, actual localhost HTTP evidence transfer, deterministic transformations, synthetic policy enforcement, seeded application-layer network emulation, and measured UTF-8 application bytes/elapsed time.

Required qualifications:

- Security classifications are a synthetic emulation profile (`syntheticProfile: true`).
- Sources are public or synthetic; labels do not establish real source sensitivity.
- There is no physical KOREN measurement or packet-level wire-byte measurement.
- Results do not guarantee privacy, security, legal compliance, or expert-validated business correctness.
- The work does not implement agent placement, migration, or replica selection.
- The six-query full HTTP study supports within-set systems effects, not broad external task generalization.
- The 40-query router study uses author labels and task adapters; it is not an exact upstream benchmark reproduction.
- The 240-query LLM-adjudicated set is provisional and remains ineligible for confirmatory claims until blind human review and agreement analysis are complete.
